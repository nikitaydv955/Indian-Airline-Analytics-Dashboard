# ✈️ Indian Airline Analytics Dashboard | Power BI

### Turning Airline Data into Meaningful Insights

## 📖 About the Project
I developed an interactive Indian Airline Analytics Dashboard using Microsoft Power BI to explore airline-related data and present key information through clear and meaningful visualizations.

The main objective was to practice data analysis, dashboard development, and storytelling through data.

## 🔍 Key Highlights
- Interactive dashboard design
- Data exploration and analysis
- KPI visualization
- Dynamic charts and filters
- Clear presentation of analytical information
